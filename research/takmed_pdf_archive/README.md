# Архив PDF-материалов по такмеду

Период текущего сбора: `2026-01-01` - `2026-08-29`, даты в Москве.

## Что открывать

- `takmed_pdf_materials_core_2026-01-01_2026-08-29.md` — основной человекочитаемый каталог: только медицинское ядро.
- `takmed_pdf_materials_core_2026-01-01_2026-08-29.csv` — та же выборка для таблицы/импорта в приложение.
- `takmed_pdf_materials_curated_2026-01-01_2026-08-29.md` — ядро плюс смежные материалы и два пункта на ручную проверку.
- `takmed_pdf_mentions_all_2026-01-01_2026-08-29.csv` — все найденные PDF-упоминания, включая исключенное как нерелевантное.
- `raw/` — сохраненные публичные HTML-страницы поиска Telegram.

## Важное ограничение

Публичный Telegram обычно отдает ссылку на пост с файлом, а не постоянную прямую ссылку скачивания. Поэтому ссылки в каталоге ведут к посту или одиночному вложению; сам PDF скачивается уже из Telegram.

## Повторный запуск

```bash
python3 scripts/collect_telegram_pdfs.py --start 2026-01-01 --end 2026-08-29 --out-dir research/takmed_pdf_archive
```
