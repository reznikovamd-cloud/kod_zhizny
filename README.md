# Код спасения

Интерактивный справочник по первой помощи, тактической, горной, спортивной и транспортной медицине. Проект содержит структурированные материалы, нормативно-правовой раздел, справочник лекарственных средств, составы аптечек и иллюстрированные способы перемещения раненых.

> Материалы предназначены для обучения и не заменяют очную медицинскую помощь, официальную подготовку или действующие локальные протоколы.

## Локальный запуск

Требуется Node.js 20 или новее и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Проверка сборки

```bash
pnpm build
pnpm start
```

## Структура

- `app/` — страницы и общие стили Next.js;
- `components/` — интерфейс справочника;
- `lib/` — медицинские материалы и данные разделов;
- `public/` — изображения и другие статические материалы;
- `research/` — рабочие текстовые исследования и подборки источников;
- `scripts/` — вспомогательные сценарии подготовки контента.

## Технологии

Next.js 16, React 19, TypeScript, Tailwind CSS и Radix UI.
